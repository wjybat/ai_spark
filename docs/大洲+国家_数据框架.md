# 海外商机决策 Agent 数据框架

###1.框架

### 1）大洲层框架

- 这个大洲的零售市场整体情况
- 这个大洲有多少零售公司、多少连锁品牌
- 这个大洲近 12 个月有哪些零售相关展会
- 这个大洲整体的市场活跃度、数字化水平、扩张信号和风险情况

---

### 2）国家层框架

- 这个国家的零售市场概况
- 这个国家有多少零售公司、多少门店、多少连锁品牌
- 这个国家主要有哪些业态，比如超市、药房、便利店、美妆等
- 这个国家零售市场的规模、增长和电商渗透情况
- 这个国家的数字化成熟度、扩张活跃度、竞争强度和进入风险
- 这个国家近期有哪些新闻、展会、公告、招聘、并购等信号

---

### 3）国家页里的市场雷达

- 这个国家值不值得重点看
- 为什么值得看
- 这个国家的机会点在哪里
- 这个国家的风险在哪里
- 这个国家适合切入哪些零售场景

---

### 4）国家页里的管理层简报

- 这个国家在区域里的优先级
- 这个国家的核心机会逻辑
- 这个国家最重要的 3-5 个机会信号
- 这个国家最重要的 3-5 个风险点
- 下一步建议怎么做
- 当前判断的置信度高不高

---

## 2. 建议重点抓的信号类型

不管是大洲层还是国家层，建议优先抓以下几类信号：

1. **扩张信号**
   
   - 开店
   - 并购
   - 区域扩张
   - 门店翻新
   - 海外进入

2. **数字化信号**
   
   - ERP / WMS / POS 招聘
   - 系统升级
   - 会员系统
   - AI 项目
   - 数据中台 / 供应链协同相关动作

3. **组织变化信号**
   
   - 新任高管
   - 数字化负责人变化
   - 供应链负责人变化

4. **采购 / 招标信号**
   
   - RFP
   - 招标公告
   - 供应商入围

5. **合作信号**
   
   - 和云厂商、咨询公司、软件公司合作

6. **战略信号**
   
   - 新业务线
   - 全渠道
   - 会员体系升级
   - 私域 / 电商布局
