# 国家地图：行政区划与代表门店

更新：2026-09-05。覆盖项目现有 11 个国家、33 家客户；每家选择一处代表门店。

## 展示口径

- 点击国家，沿地球仪最短经度方向平滑旋转并放大。国家尺寸决定放大比例，小国和大国分别适配。
- 行政区划采用 Natural Earth 1:10m ADM1 数据，经共享边界简化，表示大概省、州、地区轮廓；数据版本可能包含旧制或统计分区，不用于核定最新行政区数量。
- 门店与城市对应关系来自下表资料；坐标是城市中心附近的示意位置，不是精确门店入口。代表门店由本项目选择，不表示品牌官方认定的旗舰店。
- 美国镜头聚焦本土 48 州；加拿大与新西兰镜头聚焦主要国土。完整源几何保留，远离主视区的岛屿不扩大默认取景范围。
- 同城企业共用城市点，各自保留标签与引线。集团与经营品牌分别显示；Metcash 对应的是 IGA 独立零售网络，不能理解为该店由 Metcash 直营。
- 点击标签查看完整门店名称与资料链接，不触发客户作战包或 LLM 调用。返回大洲恢复原视角。

## 地理数据来源

[Natural Earth ADM1](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-1-states-provinces/)；[公共领域使用条款](https://www.naturalearthdata.com/about/terms-of-use/)。本地提取使用 [BenPortner/geojson-atlas 固定版本](https://github.com/BenPortner/geojson-atlas/tree/644874ada665a0f2c0c81a0d47adacea97365c30)，CC0。

构建命令（在 global-opportunity-agent 目录）：`node scripts/build-country-maps.mjs`。产物在 `global-opportunity-radar/assets/maps/`；每个国家按需加载并缓存，演示不需要实时请求外部行政区划服务。
