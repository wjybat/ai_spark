# 海外商机洞察与决策智能体 Demo

面向公司内部比赛路演的纯前端交互原型。数据为基于 PRD 结构整理的模拟数据，不代表真实 Pipeline 或客户结论。

## 本地运行

```bash
cd /Users/wangjuanyi/Projects/ai_spark/global-opportunity-radar
python3 -m http.server 4173
```

浏览器打开 `http://127.0.0.1:4173/`。

## 路演交互

- 原有五个大洲（亚洲 / 中东、欧洲、北美洲、南美洲、大洋洲）均提供“市场全景 / 展会日历 / 信号与风险”。南美洲首页展示巴西零售企业 1,175,862 家（IBGE 2024）与特许经营品牌 3,297 个（ABF 2025）；其余大洲规模卡片采用 Census、Eurostat、ABS、Stats NZ 和国家统计局公开统计，四维分数为分析研判。左侧显示国家总数：南美 12、北美 23、欧洲 44、亚洲 48、大洋洲 14；详情页单独显示资料收录数量。公开指标和活动附有来源。展会收录范围为 2025-09-01 至 2026-12-31，默认显示 5 场，可展开全部；按浏览器当前日期标注状态，全部活动按开始日期从未来到过去排列。本轮南美优先核验巴西，已收录 11 场（含综合展的零售专区），并非全年总量或穷尽清单；同期分论坛不重复计场。其他大洲目前各收录 5 场。
- 保留原有大洲入口及 11 国详情资料。区域市场总量、代表品牌和现有客户池各自独立。
- 内容集中于 `continent-data.js`。运行 `node global-opportunity-agent/scripts/export-continent-brief.mjs` 可同步生成 `docs/大洲层_市场简报.md` 中的逐项答案。

- 拖动地球旋转视角（待机时缓慢自转），悬停大洲实时预览区域机会。
- 点击大洲**锁定**选定（右侧面板保持不跳回），再次点击该区域胶囊或按 Esc 解锁。
- 锁定后地球平滑转向该区域，展示 DMALL HQ 到重点国家的出海航线；点击国家查看详细洞察。
- 点击国家后地球继续放大并聚焦该国，以细线显示行政区划；三家客户分别标注代表门店所在城市、品牌及集团。点击商家标签查看完整门店名称与来源，同城门店的标签错开排列，返回大洲恢复原视角。
- 地图内容在 `country-map-data.js`，本地行政区划在 `assets/maps/`。`node global-opportunity-agent/scripts/build-country-maps.mjs` 可重建 Natural Earth 简化边界；门店与坐标口径详见 `docs/国家地图_行政区划与代表门店.md`。行政区划和门店显示不调用模型。
- 左侧区域胶囊可免旋转直达任意大洲；底部保留九个分析流程节点展示运行进度。
- 国家详情默认打开“国家概况”，展示企业 / 门店 / 就业等公开规模指标、市场规模、增长、线上经营、业态、四维判断与动态。“市场与商机”展示各国优先判断、原因、机会、风险、试点场景与下一步，支持进入本国客户雷达。
- 原有 11 国均使用独立的国别内容。巴西采用 IBGE PAC 2024 的企业与经营网点数据、ABF 2025 的特许经营品牌数、ABRAS 2026 的食品零售营收；线上销售占比按 IBGE 各渠道销售额计算为 9.78%；其他 10 国规模、增长与线上指标均采用已附来源的公开统计，卡片注明统计对象、时期及原币单位；本国企业样本和集团背景分开标示。客户分析更新企业页面，国家生成独立更新“管理层简报”，两种结果互不覆盖。
- 国家内容集中于 `country-data.js`，页面由 `country-market.jsx` 和 `country-market.css` 呈现。运行 `node global-opportunity-agent/scripts/export-country-brief.mjs` 可同步生成 `docs/国家层_市场概况与雷达.md` 中的逐项答案。
- 客户雷达展示客户池卡片。点击已开放的公司卡片后下钻到客户层级，按客户概览、业务布局、数字化与系统、动态与组织、资料来源、销售建议、作战卡 7 个分页查看完整资料。
- 每个国家的客户雷达展示 3 家带官方来源的客户资料。当前主客户卡可下钻，另外两张资料卡保持只读，不进入客户深度分析。
- “生成 BD 作战包”展示完整智能分析过程，生成弹窗可最小化，底部节点持续显示进度；完成后可打开作战包抽屉逐项查看和复制。
- 国家页按钮为“生成国家简报”，模型读取本国三家企业完整档案后，生成优先级、机会逻辑、关键信号、风险、行动计划与置信度，并自动切到“管理层简报”。第一家公司详情内保留“生成 BD 作战包”的九步企业分析。两类结果独立，失败重试保留上次成功内容。
- “查看国家简报”即使在当前标签也会滚动到顶部并聚焦结果状态。生成前只展示六项章节占位，不展示预写正文或复制入口；步骤实时更新，完成后填入完整简报。页面使用“智能体生成简报”“国家简报已更新”等面向观众的文案，顶部保留更新时间与实际耗时，底部提供企业资料与来源。
- 三家企业补充资料集中在 `country-brief-data.js`，国家简报页面为 `country-brief.jsx`。运行 `node global-opportunity-agent/scripts/export-management-brief.mjs` 生成 `docs/国家层_管理层简报.md` 的 11 国参考答案与 33 份企业档案。文档参考答案保留在资料层；页面正文仅显示本次后端生成结果。
- 运行配置在后端目录 `.env`（已忽略提交）。OpenAI 兼容模型使用 `AGENT_PROVIDER=openai-compatible`、`AGENT_BASE_URL`、`AGENT_MODEL=qwen3.7-flash`、`OPENAI_API_KEY`；Qwen 可用 `AGENT_THINKING_EFFORT=off` 关闭思考以减少演示等待。密钥仅由后端调用模型，不进入前端。
- “重新扫描市场”会演示全球信号扫描与评分刷新。

## 界面文案原则

本演示面向不懂技术的客户管理层。前端只使用市场、客户、证据、风险、建议和行动等业务语言；不得展示框架名、模型名、推理强度、接口、运行 ID、P0 编号、LLM 或编排器等开发术语。确需追踪的信息统一称为“报告编号”，并放在折叠的报告生成信息中。

页面使用 CDN 加载 React、D3、TopoJSON 与字体，演示环境需要可访问网络。
