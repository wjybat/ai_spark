# ATLAS 海外商机决策 Agent Demo

面向公司内部比赛路演的纯前端交互原型。数据为基于 PRD 结构整理的模拟数据，不代表真实 Pipeline 或客户结论。

## 本地运行

```bash
cd /Users/wangjuanyi/Projects/ai_spark/global-opportunity-radar
python3 -m http.server 4173
```

浏览器打开 `http://127.0.0.1:4173/`。

## 路演交互

- 拖动地球旋转视角（待机时缓慢自转），悬停大洲实时预览区域机会。
- 点击大洲**锁定**选定（右侧面板保持不跳回），再次点击该区域胶囊或按 Esc 解锁。
- 锁定后地球平滑转向该区域，展示 DMALL HQ 到重点国家的出海航线；点击国家查看详细洞察。
- 左侧区域胶囊可免旋转直达任意大洲；底部保留九个分析流程节点展示运行进度。
- 国家详情包含市场与商机、客户雷达、管理层简报；点击客户雷达中的公司卡片后下钻到客户层级，查看该公司的销售建议和作战卡。
- “生成 BD 作战包”演示 7 个 Agent 的编排过程，完成后可打开作战包抽屉，逐项查看 / 复制 7 项材料（客户研究、BD 邮件、话术、Pitch 大纲、ROI 框架、CRM 任务、管理层简报），并支持整包下载。
- “重新扫描市场”会演示全球信号扫描与评分刷新。

页面使用 CDN 加载 React、D3、TopoJSON 与字体，演示环境需要可访问网络。
