# 海外商机洞察与决策智能体 Demo

面向公司内部比赛路演的纯前端交互原型。数据为基于 PRD 结构整理的模拟数据，不代表真实 Pipeline 或客户结论。

## 本地运行

```bash
cd /Users/wangjuanyi/Projects/ai_spark/global-opportunity-radar
python3 -m http.server 4173
```

浏览器打开 `http://127.0.0.1:4173/`。

## 路演交互

- 拖动地球旋转视角（待机时缓慢自转），悬停大洲实时预览区域机会。
- 点击大洲**锁定**选定（右侧面板保持不跳回），再次点击该区域胶囊或按 Esc 解锁。
- 锁定后地球平滑转向该区域，展示 DMALL HQ 到重点国家的出海航线；点击国家查看详细洞察。
- 左侧区域胶囊可免旋转直达任意大洲；底部保留九个分析流程节点展示运行进度。
- 国家详情包含市场与商机、客户雷达、管理层简报；客户雷达只展示客户池卡片。点击已开放的公司卡片后下钻到客户层级，按客户概览、业务布局、数字化与系统、动态与组织、资料来源、销售建议、作战卡 7 个分页查看完整资料。
- 每个国家的客户雷达展示 3 家带官方来源的客户资料。当前主客户卡可下钻，另外两张资料卡保持只读，不进入客户深度分析。
- “生成 BD 作战包”展示完整智能分析过程，生成弹窗可最小化，底部节点持续显示进度；完成后可打开作战包抽屉逐项查看和复制。
- “重新扫描市场”会演示全球信号扫描与评分刷新。

## 界面文案原则

本演示面向不懂技术的客户管理层。前端只使用市场、客户、证据、风险、建议和行动等业务语言；不得展示框架名、模型名、推理强度、接口、运行 ID、P0 编号、LLM 或编排器等开发术语。确需追踪的信息统一称为“报告编号”，并放在折叠的报告生成信息中。

页面使用 CDN 加载 React、D3、TopoJSON 与字体，演示环境需要可访问网络。
